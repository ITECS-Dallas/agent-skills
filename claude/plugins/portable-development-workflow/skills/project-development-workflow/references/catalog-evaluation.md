# Catalog Evaluation

This catalog is intentionally small and workflow-focused.

## Included

- Frontend implementation guardrails.
- Backend/API implementation guardrails.
- Cross-boundary testing.
- Branch and PR hygiene.
- Documentation parity.
- Reuse decisions.
- Fallback avoidance.
- Final quality review.

## Excluded

- Project-specific deployment runbooks.
- Machine bootstrap instructions.
- Secrets management for one environment.
- Client or product domain facts.
- One-off incident timelines.

Put excluded material in the owning project repository.
